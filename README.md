# DownloadsControl

Корпоративная система заявок на получение стороннего ПО. Сотрудник отправляет ссылку на файл. Фоновый обработчик получает файл в карантин и проверяет его с помощью ClamAV. Сотрудник ИБ изучает результат и вручную разрешает или отклоняет выдачу. После разрешения владелец заявки получает ссылку на внутренний файловый сервер.

Запрет самостоятельных интернет-загрузок обеспечивает существующая корпоративная инфраструктура. DownloadsControl отвечает за заявки, проверку, решения и выдачу файлов.

## Первый запуск

Нужен актуальный Docker с Compose и поддержкой монтирования подкаталога тома, а при первой сборке — доступ к реестру образов и репозиториям зависимостей. Выделите Docker около 4 ГиБ памяти для загрузки и обновления антивирусных баз. Python 3 на хосте нужен для создания файла окружения.

```sh
python3 scripts/init_compose_env.py
docker compose --env-file .env.compose up --build -d --wait --wait-timeout 360
docker compose --env-file .env.compose exec app python manage.py createsuperuser
```

Откройте `http://127.0.0.1:8080/`. Порт можно изменить через `PORTAL_PORT`. Первый запуск ClamAV может занять несколько минут. Если ожидание истекло, проверьте состояние и журналы командой `docker compose --env-file .env.compose ps -a` и `docker compose --env-file .env.compose logs setup worker clamav`. Миграции, группы и каталоги создаёт одноразовый сервис `setup`.

1. Войдите под администратором в `/admin/` и создайте два активных аккаунта с паролями. Один будет владельцем заявки, второй сотрудником ИБ.
2. Добавьте сотрудника ИБ в группу `SoftwareControl_Security`. Доступ к Django Admin ему для рассмотрения заявок не требуется.
3. Войдите как обычный пользователь и подайте заявку на прямой HTTP(S)-адрес небольшого безвредного файла. Заполните описание и обоснование.
4. Войдите как сотрудник ИБ в отдельном сеансе браузера. В `/security/` откройте заявку и дождитесь результата. При вердикте «Чистый» и отсутствии запретов появится действие «Разрешить выдачу». Для отказа укажите причину.
5. Откройте заявку под её владельцем и нажмите «Скачать файл». Уведомление о решении появится в разделе «Уведомления».

Создание заявки доступно любому активному вошедшему пользователю. Группа `SoftwareControl_Users` предназначена для организационного учёта. Права просмотра очереди, согласования и отказа выдаются группе ИБ и `SoftwareControl_Admins`. Политиками и учётными записями управляют через админку с соответствующими правами.

Скрипт создаёт `.env.compose` с правами `0600` и отдельными секретами. Прежний локальный `.env` используется при запуске Django вне Compose. Проект Compose по умолчанию называется `downloadscontrol-v1` и получает собственные тома. Порядок работы с существующими данными описан в [документации](docs/architecture.md).

## Интерфейс и API

| Адрес | Действие |
| --- | --- |
| `/`, `/requests/new/`, `/requests/{id}/` | Список, подача и просмотр своих заявок |
| `/security/`, `/security/{id}/` | Очередь ИБ, результаты и решение |
| `/notifications/` | Уведомления о ходе заявки, решении и истечении срока выдачи |
| `POST /api/v1/requests/create/` | Создать заявку. Поля `source_url`, `description`, `business_reason` |
| `GET /api/v1/requests/{id}/` | Статус заявки и `download_url`, если файл доступен владельцу |
| `GET /api/v1/security/requests/{id}/` | Сведения о файле, результат ClamAV и причины, запрещающие согласование |
| `POST /api/v1/security/requests/{id}/approve/` | Разрешить выдачу. `security_comment` обязателен для исключения из реестра |
| `POST /api/v1/security/requests/{id}/reject/` | Отказать с обязательным `security_comment` |
| `POST /api/v1/security/requests/{id}/reprocess/` | Явно повторить обработку заявки с ошибкой или без достоверной проверки |
| `GET /downloads/{id}/` | Скачать одобренный файл в сеансе владельца заявки |
| `/api/schema/`, `/api/docs/` | OpenAPI и Swagger |
| `/healthz/`, `/readyz/` | Проверки HTTP, PostgreSQL, Redis и хранилища |

API принимает авторизацию Django-сессией с CSRF для изменений либо HTTP Basic. Для скачивания по ссылке используется Django-сессия. Открытые в этой сессии ссылки на выдачу работают до окончания срока хранения. При авторизации каждого запроса сервер проверяет владельца, решение ИБ и доступность файла.

## Правила текущей версии

- Принимаются прямые HTTP/HTTPS-ссылки, включая прямые ссылки на файлы, которые перенаправляют на CDN. Стартовая политика разрешает порты 80 и 443, запрещает локальные и служебные адреса, HTML-страницы и файлы больше 50 МиБ. Разрешение частных адресов требует явного списка доверенных доменов.
- Файл остаётся в карантине до положительного результата ClamAV и разрешения ИБ. Подозрительный результат, обнаружение сигнатуры, недоступный сканер, отсутствие проверки и прежний `MOCK` не дают право на выдачу. Ошибку можно изучить, отказать или повторить обработку из очереди ИБ.
- Администратор может настроить правила типов файлов и реестр запрещённого ПО. Правило с разрешённым исключением требует комментария ИБ. Типы, для которых настроена обязательная отдельная песочница или распаковка, блокируются до появления соответствующего этапа.
- Сроки хранения по умолчанию — 14 дней в карантине, 30 дней после разрешения, 7 дней после отказа. Они задаются в `.env.compose`. С истечением срока выдача прекращается сразу, а периодическая очистка удаляет файл и сохраняет историю.
- Аккаунты и группы локальные. AD, 1С, внешние антивирусы, SMTP и собственные API облачных дисков — отдельные интеграции. Установка ПО, инвентаризация и лицензии находятся за границами системы.

## Проверки для разработчика

```sh
poetry install --no-root
poetry run python manage.py test --settings=config.test_settings
poetry run python manage.py makemigrations --check --dry-run --settings=config.test_settings
poetry run python manage.py spectacular --validate --fail-on-warn --settings=config.test_settings
```

Тестовые настройки используют SQLite в памяти, временное хранилище и брокер в памяти. Проверка параллельного захвата задачи выполняется на PostgreSQL. Внешний HTTP и ответы ClamAV в модульных тестах подменены безопасными данными. Для Linux/macOS вне Docker нужна системная библиотека `libmagic` (например, `brew install libmagic` на macOS).

Подробности модулей, параметров для корпоративного HTTPS, переноса данных и сквозной проверки — в [описании архитектуры](docs/architecture.md).
