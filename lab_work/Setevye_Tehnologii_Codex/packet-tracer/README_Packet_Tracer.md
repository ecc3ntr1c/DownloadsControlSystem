В папке `pkt` лежат 11 проектов на основе формата Cisco Packet Tracer 8.2.1. Конфигурации и соединения уже записаны в проектах. Для ЛР № 1–3 использован демонстрационный номер **N = 3**. ЛР № 4 рассчитана для **варианта 4**. Если номер в журнале отличается, см. раздел о пересчёте.

Файлы проверены программным чтением после записи. Загрузка и результаты работы в интерфейсе Cisco Packet Tracer в этой среде не проверены. Проверки связи и вывод команд нужно получить непосредственно в симуляторе.

## Открытие и снимки на Mac

1. Распакуй архив целиком. В Packet Tracer выбери **File → Open** и открой нужный файл из папки `pkt`.
2. Оставь рабочую область **Logical** и режим **Realtime**. Дождись завершения загрузки портов. Если нужно ускорить ожидание, нажми **Fast Forward Time**. В треугольнике STP резервный порт может остаться оранжевым.
3. На Mac нажми **⇧⌘4** и выдели нужную часть экрана. Для снимка окна целиком нажми **⇧⌘4**, затем **Пробел** и щёлкни по окну.
4. Для команд ПК открой **PC → Desktop → Command Prompt**. Для маршрутизатора или коммутатора открой **CLI**, нажми Enter и при приглашении `>` введи `enable`. Команды `show` только показывают состояние. Если видишь `--More--`, нажми пробел для продолжения вывода.
5. Для **Simple PDU** нажми кнопку с закрытым конвертом, затем щёлкни по ПК-источнику и ПК-назначению. При первом запросе после открытия может понадобиться заполнить ARP. Повтори проверку после короткого ожидания.

## ЛР № 4. DHCP и маршрутизация

1. Открой `04a_DHCP_static.pkt`. Сними топологию. На PC1, PC3 и PC5 открой **IP Configuration** или введи `ipconfig` в **Command Prompt**. Дождись аренды. Если поле IPv4 остаётся пустым, на клиенте введи `ipconfig /renew`, затем `ipconfig`. На маршрутизаторах выполни `show ip dhcp binding`.
2. В том же файле открой `show ip interface brief` и `show ip route` на маршрутизаторах. В таблицах должны быть статические строки `S`. Выполни `ping 192.168.3.254` с PC1 и `ping 192.168.1.254` с PC3.
3. Открой `04b_DHCP_static_RIPv2.pkt` и дай RIPv2 время обменяться маршрутами. На Router0 и Router2 выполни `show ip protocols` и `show ip route`. Сними строки `R`. На PC0 выполни `ping 192.168.1.254`, на PC4 — `ping 192.168.4.30`.

## Пересчёт по номеру в журнале

Готовые проекты запускаются в Packet Tracer без Python. Скрипт нужен только для пересчёта. В папке `generator` запусти в Terminal команды ниже, заменив `3` на свой номер в последней строке. Нужен Python 3.10 или новее. Для другого номера ориентируйся на обновлённый `addresses.json` в папке новых проектов. Вариант ЛР № 4 пересчитывается по формуле `N % 5 + 1`.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python make_pkt.py --number 3 --out ../pkt_regenerated
```

Инструменты генерации и источники шаблонов перечислены в `generator/THIRD_PARTY.txt`.
