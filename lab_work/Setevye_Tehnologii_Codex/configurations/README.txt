Состав
  stand.py         Адресация, формирование конфигураций и учебная модель.
  run/cisco/       Готовые команды по устройствам и этапам.
  run/results.json Адреса, таблицы, результаты и трассы модели.

Для пересчёта нужен Python 3.10 или новее. Внешних библиотек нет.
  python3 stand.py --number 3 --out run
В архиве демонстрационный N = 3, соответствующий варианту 4.
Подставьте свой порядковый номер в журнале вместо 3. Число N
используется в работах 1–3. В работе 4 вариант равен N % 5 + 1.

Файлы IOS предназначены для учебных стендов Cisco Packet Tracer.
Конфигурация пересчитывается из одних данных для отчёта и исходников.
Локальная модель проверяет логические пути и состояние схем, но не
реализует Cisco IOS, таймеры протоколов и задержки передачи.

ВОСПРОИЗВЕДЕНИЕ В CISCO PACKET TRACER

В каждом пункте модели и имена устройств соответствуют методичке.
IP-адреса ПК, маски, шлюзы и порты берутся из run/results.json или
из таблиц отчёта. Конфигурацию каждого устройства введите в его CLI.
Если при первом включении предлагается диалог initial configuration,
ответьте no. Подождите выхода интерфейсов и STP в рабочее состояние.

ЛР 1
1. Добавьте Router0 Cisco 2811, два 2960 и шесть PC-PT. Подключите
   PC1–PC4 к Fa0/1–Fa0/4 Switch0, PC5–PC6 к Fa0/1–Fa0/2 Switch1.
   Router0 Fa0/0 соедините с Switch0 Fa0/24, Fa0/1 — с Switch1 Fa0/24.
2. Примените lab1/Router0.txt. Назначьте адреса и шлюзы в Desktop →
   IP Configuration на ПК.
3. Снимки для отчёта: топология, IP Configuration PC1/PC5, состояние
   обоих интерфейсов Router0, тесты ping внутри сегмента и между
   сегментами, список событий Add Simple PDU.

ЛР 2
1. Добавьте три 2960 и 13 PC-PT. Свяжите Switch0 Gi0/1 с Switch1 Gi0/1,
   Switch1 Gi0/2 с Switch2 Gi0/1. Подключите ПК к access-портам как
   указано в run/results.json → lab2 → pcs. Назначьте IP и маски.
2. Примените 01-access-trunk на трёх коммутаторах. Шлюз пока
   оставьте пустым. Проверьте PC11 → PC21/PC31 и PC11 → PC12/PC34.
3. Подключите Cisco 2901 Router0 Gi0/0 к Switch2 Gi0/2 и примените
   02-router-on-a-stick. Назначьте шлюзы ПК в VLAN 10/20/30.
   Повторите ping или Add Simple PDU между VLAN.
4. Чтобы выполнить проверку доступности всех ПК, примените 03-all-pcs.
   Назначьте PC14 и PC32 шлюз 192.168.0.254. Проверьте PC14 → PC32
   и PC14 → PC11.
5. Снимки: топология до и после, IP Configuration PC11, show vlan,
   show vlan brief, show running-config на Switch0, show interfaces
   trunk на трёх коммутаторах, show running-config на Router0,
   список событий PDU до и после маршрутизации.

ЛР 3
1. Добавьте три 2960. PC0, PC1, PC2 подключите к Fa0/1 коммутаторов
   Switch0, Switch1, Switch2 соответственно. Соедините Switch0
   Fa0/2 — Switch2 Fa0/2, Switch0 Fa0/4 — Switch1 Fa0/4 и Switch1
   Fa0/5 — Switch2 Fa0/5. Примените 01-initial. Шлюзы оставьте пустыми.
2. Введите show spanning-tree vlan 1 на всех трёх коммутаторах.
   MAC-адреса устройств определяют исходный корень при равных
   приоритетах. Для назначения нового корня примените 02-root на
   некорневом коммутаторе. В приложенном файле выбран Switch2.
   Если он уже корень в вашей копии, выберите другой коммутатор.
3. Добавьте второй кабель Switch0 Fa0/3 — Switch2 Fa0/3. Проверьте
   роли портов. Примените 03-lacp на Switch0 и Switch2, затем
   show etherchannel summary и show spanning-tree vlan 1.
4. Проверьте ping PC0 → PC2. Примените 04-failure на Switch0,
   повторите ping и show etherchannel summary.
5. Только в этом отдельном учебном файле сохраните копию перед
   демонстрацией петли. Перейдите в Simulation и оставьте фильтр ARP.
   Примените 05-isolated-storm к трём коммутаторам, отправьте PDU
   с PC0 на PC1 и проследите несколько повторов ARP через Capture/Forward.
   Примените 06-restore, сначала включив STP на каждом коммутаторе.
6. Снимки: схема, исходные роли, новый корень, LACP, доступность
   при отключённом Fa0/3 и список повторяющихся ARP в режиме Simulation.

ЛР 4 (раздел 7 методички)
1. Добавьте три Router PT Empty, три 2960 и шесть PC-PT. На каждом
   Router PT Empty установите два медных GigabitEthernet модуля в
   слоты 8/9 и один FastEthernet модуль в слот 7 при выключенном
   питании. Включите питание. Проверьте порты show ip interface brief.
2. Соединения: Router0 Gi9/0 — Router1 Gi9/0, Router1 Gi8/0 —
   Router2 Gi9/0, Router0 Gi8/0 — Router2 Gi8/0. Fa7/0 каждого
   маршрутизатора соедините с Fa0/24 его Switch. На Fa0/1 и Fa0/2
   подключите ПК соответствующей LAN.
3. Примените 01-interfaces. ПК PC0/PC2/PC4 назначьте последний
   пригодный адрес своего сегмента, шлюз — адрес Fa7/0.
4. Примените 02-dhcp. ПК PC1/PC3/PC5 переведите в DHCP, выполните
   ipconfig /renew и ipconfig. Сверьте show ip dhcp binding.
5. Примените 03-static, проверьте LAN1↔LAN2 и LAN2↔LAN3.
   Примените 04-ripv2 на Router0 и Router2, проверьте show ip route,
   show ip protocols и доступность PC0↔PC4.
6. Снимки: топология, show ip interface brief, адреса DHCP-клиентов,
   show ip dhcp binding, маршруты S и R и успешные проверки ping.
